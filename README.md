# Thai Adult Vaccine Guide 2026

A searchable vaccine database by Warodom Phaenthong, M.D., built from the Infectious Disease Association of Thailand
(IDAT) **Recommended Adult and Elderly Immunization 2026** (คำแนะนำการให้วัคซีนป้องกันโรคสำหรับผู้ใหญ่และผู้สูงอายุ
ปี พ.ศ. 2569). It is one self-contained HTML page (`vaccine-guide.html`, opened by `index.html`) that runs in the browser,
with no installation and no data sent anywhere.

It is a teaching and decision-support aid for healthcare professionals, not a substitute for clinical judgement,
the full guideline, or the product label.

## What it does

- 17 vaccines, each with the guideline's vaccine information, administration, side effects / precautions /
  contraindications, additional recommendations and references, in Thai (original wording) and English.
- Filters by age group (Table 1), condition (Table 2: pregnancy, healthcare personnel, heart/diabetes/lung disease,
  CKD, liver disease, asplenia, HIV, immunocompromise, transplant, travellers), recommendation level, live / non-live,
  and "updated in 2026". Search covers names, brands and the full text.
- One **Tables** guide with Table 1 (by age) and Table 2 (by condition): each shows as a colour-coded table, and its **PDF** switch shows that table's page of the original PDF
  in the page (pdf.js from cdnjs; falls back to page pictures offline), with Open / Save when the page is not framed.
- Pneumococcal pathway: pick age, highest-risk condition and previous vaccines, and it summarises the plan from
  Tables 3 and 4 (both options as dose timelines, the footnotes that apply, reminders, Copy plan); the full tables stay
  below as folded details.
- Hepatitis B Figure 1, and guides for pregnancy, solid organ and stem cell transplant, asplenia, travellers, and the
  general principles of adult vaccination.
- Light and dark themes, Thai / English, phone layout, colour-coded blocks that fold.

Tap the version badge next to the title for the changelog.
